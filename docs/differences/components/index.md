## 说明

- 2.0 新增的组件不属于「差异」范畴，其用法请直接查阅[组件文档](/components/index)，本索引不再收录。
- 被更名或重构的组件（如 `sn-longlist` → `sn-list-view`、`sn-waterfall` → `sn-waterflow`、`sn-form-item` → `sn-form-field`）在新旧两侧名称下均有说明：新名称页面描述差异明细，旧名称页面描述删除原因与替代方案。
