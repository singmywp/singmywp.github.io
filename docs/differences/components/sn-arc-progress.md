# sn-arc-progress
> 旧版组件：无（v2 新增）
**旧版状态**：旧版无此组件，SinleUI 2.0 新增的环形（圆弧）进度组件，基于 canvas 绘制。
**差异明细**：
- 新增属性：全部（v-model、size、startAngle、endAngle、lineCap、strokeWidth、strokeColor、trailWidth、trailColor、min、max、showValueText、aniTime、customStyle、customClass）
- 移除属性：无
- 更名：无
- 类型或默认值变化：无
- 行为变化：无（组件为 v2 全新提供：v-model 绑定进度值并自动夹取、自定义起止角度支持仪表盘与完整圆环、进度变化缓动动画、value 作用域插槽自定义中心内容、主题/风格变化自动重绘等）
- 新增事件、方法、插槽：无（事件 change / finish 与 value 插槽均为 v2 全新提供，无对外方法）
