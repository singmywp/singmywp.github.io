# sn-calendar-week
> 旧版组件：无（v2 新增）
**旧版状态**：旧版无此组件，SinleUI 2.0 新增的周日历（一次显示一周，可滑动切周）。
**差异明细**：
- 新增属性：全部（minDate、maxDate、disabledDates、weekStart、weekTitles、showSwitch、switchIconSize、switchIconColor、selectedBgColor、selectedTextColor、format 及 customStyle / customClass 与 switch / weeks / week / day / dayTitle / dayText 等外部样式类）
- 移除属性：无
- 更名：无
- 类型或默认值变化：无
- 行为变化：无（组件为 v2 全新提供：滑动切周、按钮按日粒度移动选中日期、weekStart 周起始日与自定义周标题、disabledDates 禁用日期、format 返回 showDot / dotColor 绘制事件圆点）
- 新增事件：select、change、week-change
- 新增方法：scrollToDate
- 新增插槽：无
