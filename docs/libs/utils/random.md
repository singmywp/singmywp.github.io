# snu.randint()

### **生成随机整数**

生成一个介于最小值和最大值之间（均包含）的随机整数。当 `max < min` 时返回 `0`。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

| 名称 | 类型   | 必备 | 默认值 | 描述 |
| ---- | ------ | ---- | ------ | ---- |
| min | Number | 是 | - | 最小值（包含） |
| max | Number | 是 | - | 最大值（包含） |

### 返回值

| 类型   | 必备 | 描述 |
| ------ | ---- | ---- |
| Number | 是   | `[min, max]` 区间内的随机整数；`max < min` 时返回 `0` |

### 示例

```typescript
let n = snu.randint(1, 10)
```

# snu.randomNumber()

### **生成指定位数随机数**

生成一个指定位数的随机整数。`digit` 为 0 时返回 `0`。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

| 名称  | 类型   | 必备 | 默认值 | 描述 |
| ----- | ------ | ---- | ------ | ---- |
| digit | Number | 是 | - | 数字位数（如 `4` 生成 1000~9999） |

### 返回值

| 类型   | 必备 | 描述 |
| ------ | ---- | ---- |
| Number | 是   | 指定长度的随机整数 |

### 示例

```typescript
let code = snu.randomNumber(4) // 4 位随机数
```

# snu.uuid()

### **生成 UUID 字符串**

生成一个符合 UUID 规范（v4 风格）的随机字符串，格式形如 `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

无

### 返回值

| 类型   | 必备 | 描述 |
| ------ | ---- | ---- |
| String | 是   | 生成的 UUID 字符串 |

### 示例

```typescript
const id = snu.uuid()
```

# snu.randomComId()

### **生成随机组件 ID**

生成一个以英文字母开头的随机 ID（字母 + UUID），可用于组件或元素的唯一标识，避免以数字开头带来的 CSS 选择器或标识符问题。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

无

### 返回值

| 类型   | 必备 | 描述 |
| ------ | ---- | ---- |
| String | 是   | 以字母开头的随机组件 ID |

### 示例

```typescript
const comId = snu.randomComId()
```
