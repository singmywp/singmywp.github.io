# snu.isEmpty()

### **判断字符串是否为空**

判断字符串是否为空或仅含空白字符（`null`、`''`、空格等均视为空）。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

| 名称 | 类型     | 必备 | 默认值 | 描述 |
| ---- | -------- | ---- | ------ | ---- |
| str | String/null | 是 | - | 待判断的字符串 |

### 返回值

| 类型    | 必备 | 描述 |
| ------- | ---- | ---- |
| Boolean | 是   | 是否为空或空白 |

### 示例

```typescript
let r1 = snu.isEmpty('')     // true
let r2 = snu.isEmpty(' x ')  // false
```

# snu.roundAmount()

### **金额取整**

对金额进行四舍五入/向上/向下/截断取整，并补足指定位小数，返回格式化后的字符串。`mode` 决定取整方式：

- `round`：四舍五入
- `ceil`：向上取整
- `floor`：向下取整
- `trunc`：直接截断（舍弃多余小数位）

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

| 名称     | 类型          | 必备 | 默认值     | 描述 |
| -------- | ------------- | ---- | ---------- | ---- |
| value | String/Number | 是 | - | 金额值 |
| decimals | Number | 否 | `2` | 保留的小数位数 |
| mode | String | 否 | `'round'` | 取整方式：`round` / `ceil` / `floor` / `trunc` |

### 返回值

| 类型   | 必备 | 描述 |
| ------ | ---- | ---- |
| String | 是   | 取整并补足小数位后的金额字符串 |

### 示例

```typescript
let a = snu.roundAmount('123.456', 2, 'round') // '123.46'
let b = snu.roundAmount('123.451', 2, 'ceil')  // '123.46'
let c = snu.roundAmount('123.456', 2, 'trunc') // '123.45'
```

# snu.encryptName()

### **姓名脱敏**

对姓名进行脱敏处理：两个字的姓名保留首字，第二个字用 `*` 替代；超过两个字的保留首尾字，中间用 `*` 替代；两个字符以内的原样返回。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

| 名称 | 类型   | 必备 | 默认值 | 描述 |
| ---- | ------ | ---- | ------ | ---- |
| name | String | 是 | - | 姓名 |

### 返回值

| 类型   | 必备 | 描述 |
| ------ | ---- | ---- |
| String | 是   | 脱敏后的姓名 |

### 示例

```typescript
let s = snu.encryptName('张三三') // '张*三'
```

| ------ | ---- | ---- |
| String | 是   | 脱敏后的号码 |

# snu.separateNumber()

### **数字千分位分隔**

为数字字符串添加千分位分隔符（默认每 3 位加逗号），保留原有小数部分与符号。`digits` 不能为 0 且需为纯数字字符串，否则抛出 `UniError`。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

| 名称      | 类型   | 必备 | 默认值 | 描述 |
| --------- | ------ | ---- | ------ | ---- |
| num | String | 是 | - | 数字字符串（如 `'1234567.89'`） |
| digits | Number | 否 | `3` | 每组分隔的位数 |
| separator | String | 否 | `','` | 分隔符 |

### 返回值

| 类型   | 必备 | 描述 |
| ------ | ---- | ---- |
| String | 是   | 千分位分隔后的字符串 |

### 示例

```typescript
let s = snu.separateNumber('1000000.50', 3, ',') // '1,000,000.50'
```
