# snu.isDate()

### **判断是否为有效日期**

判断传入值是否为有效日期。空字符串、`null` 及非法日期均返回 `false`。

### 兼容性

| Web | Android |
| --- | ------- |
| √   | √       |

### 属性

| 名称 | 类型 | 必备 | 默认值 | 描述 |
| ---- | ---- | ---- | ------ | ---- |
| date | any | 是 | - | 待判断的日期 |

### 返回值

| 类型    | 必备 | 描述 |
| ------- | ---- | ---- |
| Boolean | 是   | 是否为有效日期 |

### 示例

```typescript
let r = snu.isDate('2026-01-01') // true
```
